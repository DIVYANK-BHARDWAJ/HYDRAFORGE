BASINSHIFT 2026 • Machine Learning for Hydrology

Train anywhere. Predict anywhere. Prove your model.

BASINSHIFT is an automated scientific benchmark evaluating river-discharge forecasting models, uncertainty calibration, and unseen-catchment generalization under real-world distribution shift. Participants may train using any scientifically valid, legally permissible dataset.

Challenge Overview

Accurate river-discharge prediction is essential for early flood warning, reservoir operation, and water resource management. Standard machine learning models often degrade catastrophically when transferred to ungauged river basins or exposed to extreme meteorological shifts.

HYDRAFORGE evaluates submitted GitHub repositories containing trained models or forecasting agents against organizer-controlled, unseen benchmark catchments and hidden ground-truth labels. The scoring engine evaluates your architecture across six distinct deterministic dimensions.

Evaluation Dimensions

* Weights are provisional until organizer ratification. Composite score is bounded in [0, 100].

1. Forecast Skill 25 pts

Continuous discharge accuracy evaluated via Nash-Sutcliffe Efficiency (NSE), MAE, and RMSE against a persistence baseline.

2. Event Detection 25 pts

Skill in detecting Q95 high-flow and Q99 extreme flood peaks using prevalence-normalized AUPRC, Brier Skill Score, and CSI.

3. Generalization 20 pts

Performance retention on completely unseen, out-of-distribution catchments (Test B) with penalties for cross-regional disparity.

4. Calibration 15 pts

Probabilistic interval validity: 90% prediction interval coverage error, sharpness, CRPS, and PIT histogram uniformity.

5. Robustness 10 pts

Resilience to paired adversarial corruptions: Gaussian sensor noise, historical data missingness, and sensor bias shifts.

6. Efficiency 5 pts

Inference computational footprint: latency per prediction step (<50 ms target) and peak resident container RAM (<4 GB).

Submission Requirements & Rules

Repository & Code Format

  • Public GitHub or GitLab repository.
  • Immutable 40-character commit SHA (mutable branch references rejected).
  • Must contain a compliant submission_manifest.json.
  • Executable entrypoint script outputting valid JSON predictions.

Dataset & License Disclosure

  • Open training data policy (no closed whitelist).
  • Full disclosure of dataset sources, licenses, and preprocessing.
  • Pretrained weights and supplementary data must be declared.
  • Inference-time data must not contain future ground-truth targets.
